# Changelog

Заметные изменения Conductor. Формат свободный, даты — ISO.

## v2.1.0 — 2026-08-15

Язык и волна ремонта по внешнему ревью.

- **Язык переключается целиком.** Корпус правил переведён на английский (русский корпус
  утягивал видимые рассуждения в русский при любом выборе языка); язык ответов — одна
  подставляемая фраза «Answer in Russian»; рассуждения идут на выбранном языке. Выбор
  делается в меню терминала при каждом запуске установщиков (Enter = прежний выбор),
  хранится в `~/.claude/conductor/reply-language`, его применяют все три установщика.
  Запрет `--no-verify` убран из правил (решение автора: коммит не блокируется — дисциплина
  в доказательстве до коммита).
- **Память починена.** Индекс уроков пересобирается из стора (повторная дистилляция его
  больше не стирает); инжект берёт новейшие строки и режет блок целыми строками (байтовый
  `cut` ломал UTF-8); инбокс ротируется до чтения (гонка закрыта); строки без `|` не
  файлятся мусором; DISTILL DUE напоминается каждым сообщением.
- **Инструменты.** `tools/doctor.sh` — здоровье установки; `tools/journal-report.sh` —
  чтение журнала прогонов с вердиктом достаточности данных (≥200 строк / ≥3 репозитория /
  ≥21 день); sentinel в `settings-json.py` заякорен (semiconductor-* больше не матчится).
- **Тесты и CI.** `qa/settings-json-test.py` (10 тестов на самый опасный код),
  `qa/lint-selftest.sh` (13 негативных кейсов линта), GitHub Actions на ubuntu + windows.
- **Правила откалиброваны.** Пороги fan-out при исследовании: >20 файлов / >1500 строк
  (углы поиска — не триггер); немутирующим задачам дан вход в тиры; лок/генерат исключён
  из RE-TIER; ложный маркер озвучивается раз за сессию; CONTROL GROUP сужен до артефактов
  дисциплинарного слоя; cross-model верификатор — из `crossmodel.conf`, не из зашитого CLI.
- LICENSE (MIT), англоязычный `README.en.md`, документированы побочные эффекты установки.

## v2.0.0 — 2026-07-28

Волна v2.0 (ретроспективный тег не ставился; состояние описано в HANDOFF.md).

- Весь слой доставки переведён на bash; PowerShell удалён.
- Правила приведены к документации Anthropic поколения Opus 5 / Fable 5 / Sonnet 5.
- Один источник дайджестов (`adapters/core-body.md` + `tools/build-digests.sh`).
- Память двухступенчатая: инбокс + курируемый стор с индексом.
- Журнал прогонов тестов (`test-run-journal.sh`) — пассивный неподделываемый след.
- Маркерный коммит-гейт удалён окончательно; бенчмарк удалён (итоги — в HANDOFF).
