# HANDOFF — состояние проекта Conductor

Обновлено: 2026-08-15 (язык ответов — один подставляемый токен, корпус правил переведён
на английский; до этого 2026-07-28: волна v2.0 — переход на bash, правка правил под
поколение Opus 5 / Fable 5 / Sonnet 5, журнал прогонов тестов). Написано для читателя
с нулевым контекстом.

## Что это

Conductor — дисциплинарная система для AI-агентов: классификация задачи до работы,
доказательство до слова «готово» и до коммита, самообучение через общую память.
Покрывает четыре среды: Claude Code (ядро + хуки), Cursor, Antigravity, Codex
(текстовые дайджесты правил). Репозиторий — источник правды и одновременно дистрибутив.

## Текущее состояние

- **Весь слой доставки на bash.** PowerShell в репозитории не осталось (0 файлов `.ps1`).
  Хуки не требуют внешних зависимостей; установщикам нужен `python3` — только для правки
  JSON-конфигов, принадлежащих другим инструментам.
- Задеплоено и проверено на этой машине; хук `rtk` пользователя и его `graphify` /
  `@RTK.md` в глобальном `CLAUDE.md` сохранены.
- **Маркерный гейт снят окончательно:** 104 хука в 26 репозиториях под `D:\top`,
  `D:\projects`, `D:\codelabs` удалены, 2 вытесненных чужих хука восстановлены,
  контрольный прогон даёт 0. Инструмент: `tools/sweep-git-gate.sh`.
- **Память перестроена:** 152 накопленных урока разложены по файлам с индексом.

| Дайджест | `adapters/core-body.md` — **единственный источник**; `tools/build-digests.sh` собирает из него файлы Cursor и Antigravity | Cursor, Antigravity, Codex |

Установка: `install.sh` (Claude Code; язык ответов — меню при каждом запуске с
сохранённым выбором по умолчанию, `--language <имя>` пропускает вопрос),
`install-global.sh` (Cursor/AG/Codex + пересборка глобального
CLAUDE.md, язык спрашивает так же), `install-project.sh
--repo <путь>` (проектные адаптеры; подставляет сохранённый язык, `--language` —
переопределение только для этого проекта, машинный выбор не трогает), `uninstall.sh`
(симметричное удаление, есть `--dry-run`). Выбор языка хранится в
`~/.claude/conductor/reply-language`; повторные запуски установщиков его не сбрасывают.

## Ключевые решения волны v2.0

- **Правила приведены к документации Anthropic** по Opus 5 / Fable 5 / Sonnet 5:
  - убрана избыточная верификация как инструкция (модели перепроверяют себя сами);
    скептик больше не обязателен на каждом T3 — он для работы, которую ты не видел;
  - роли разведены: ОРКЕСТРАТОР (главная сессия) делегирует крупное и независимое,
    не делегирует мелочь, не проверяет субагентом свою же работу; ИСПОЛНИТЕЛЬ (контракт
    субагента) не делегирует дальше, применяет инструкции ровно в заданной области,
    при поиске дефектов отдаёт всё найденное без самофильтрации;
  - добавлен раздел про длинные автономные прогоны: сверка заявлений с результатами
    инструментов, запрет заканчивать ход обещанием, запрет сворачиваться из-за бюджета
    контекста, пауза только для необратимого/смены объёма/ввода пользователя;
  - effort привязан к тирам (T1 low/medium, T2 high, T3 xhigh);
  - ограничение объёма («не рефактори вокруг фикса») — в `implementing.md` и дайджестах;
  - стиль ответа (сначала итог, читаемость важнее краткости, длина письменных
    артефактов) — в `deploy/global-CLAUDE.md`, у которого нет лимита размера.
- **Один источник дайджестов.** Файлы Cursor и Antigravity были байт-в-байт одинаковыми
  и синхронизировались руками — постоянный генератор расхождений. Теперь тело общее,
  заголовки свои, линтер падает на устаревшем сгенерированном файле.
- **Линтер усилен двумя правилами из документации:** запрет формулировок, требующих
  пересказать внутренние рассуждения (у Fable 5 это классификатор отказа с откатом на
  Opus 4.8), и запрет инструкций «перепроверь себя». Плюс проверка синтаксиса всех
  shell-скриптов. Каждое правило проверено намеренным нарушением.
- **Память двухступенчатая.** Раньше журнал был одним файлом, а впрыскивались только
  10 верхних строк: 142 урока лежали на диске и были невидимы. Теперь входящее
  (дёшево записать) отделено от разобранного (индекс из однострочников, читается
  по необходимости), и рост памяти больше не означает её потерю.
- **Журнал прогонов тестов** (`runtime/hooks/test-run-journal.sh`, события `PostToolUse` и
  `PostToolUseFailure`, матчер `Bash`). Записывает факт выполнения тестов: время, исход,
  полноту прогона, репозиторий, команду, коммит и хеш рабочего дерева — в
  `~/.claude/conductor/test-runs.log`. **Ничего не блокирует.** След не создаётся отдельным
  действием: он побочный продукт самой команды и несёт её настоящий код возврата, поэтому
  подделать его нельзя так, как подделывался маркер. Конвейер (`npm test | tail`) отдаёт код
  возврата последней команды — такой случай помечается как «нельзя отнести», а не успехом.
  Собственная стоимость около 2 мс поверх запуска процесса. Ограничение: видны только
  команды, прошедшие через агента.
  Зачем: `qa/reports/baseline.md:65` требует решать вопрос об урезании правил по данным
  живой работы, а ловушки этот класс задач воспроизвести не могут — журнал их и даёт.
- **Условие про файл ценностей записано в оба README.** Контрольная группа показала
  поведение без Conductor, но с глобальным `CLAUDE.md`; значит удаление этого файла тихо
  снимает дисциплину целиком. Теперь это условие работоспособности, а не примечание.
- **Разбор правил по корзинам проведён** (дублирует / спорит / добавляет / не проверено).
  Удаление НЕ выполнялось сознательно: тот же `baseline.md:65` постановил решать по живым
  данным. Разбор станет входными данными, когда журнал накопит их.
- **Язык — один токен, корпус — английский (2026-08-15).** `deploy/global-CLAUDE.md`
  переведён на английский: модель рассуждает на языке своих инструкций, и русский корпус
  утягивал видимые рассуждения в русский даже при выборе AZ/EN (при этом старый
  `install-global.sh` подменял лишь одну фразу, а повторный `install.sh` молча возвращал
  русский). Язык ответов — единственная подставляемая фраза «Answer in Russian»
  (общий код — `tools/reply-language.sh`); выбор сохраняется в
  `~/.claude/conductor/reply-language`, его подставляют все три установщика, включая
  `install-project.sh`. Рассуждения (видимый thinking) идут на выбранном языке ответов —
  решение пользователя от 2026-08-15 (первая редакция фикса ставила «всегда на
  английском»); задаётся явной строкой правил, не подстановкой. Линт охраняет токен,
  правило о языке рассуждений и отсутствие кириллицы в корпусе (байтовая проверка,
  не зависит от локали); каждое правило проверено намеренным нарушением.

## Бенчмарк удалён (2026-07-28). Авторизации и ключей в проекте нет

**Conductor не требует авторизации.** Ключи нужны были только измерительному прибору, а не
системе: сломанная авторизация никогда не мешала Conductor работать. Прибор удалён целиком —
`qa/run-benchmark.sh`, сценарии, пять ловушек-фикстур, изолированные каталоги настроек и
стенограммы прогонов. Ключей в репозитории нет и не будет.

Что прибор успел доказать до удаления (единственный состоявшийся прогон, сценарий `verify`):

- **Плечо с Conductor доказано сквозным прогоном.** Сентинел `CONDUCTOR-CORE-v1-7f3a` в
  стенограмме дважды, ноль записей `hook_non_blocking_error`, и — главное — строка
  `Conductor: debug | T1 | core only` в ответе агента. Последнее важнее первого: сентинел
  показывает, что текст доставлен, а объявление типа и уровня — что правила **сработали**.
- **Контрольное плечо не измерялось.** Отказ аутентификации. Причина доказана контрольными
  суммами: прогон обновил OAuth-токен, обновление отзывает прежний, и вторая копия с тем же
  токеном стала недействительной. Два плеча не могут работать от одной скопированной пары
  ключей — кто первым обновит, тот отзовёт у остальных.

Почему прибор не чинили дальше, а убрали: `qa/reports/baseline.md:62-63` прямо говорит, что
эти ловушки не воспроизводят длинные сессии, ради которых правила и держат. Чинить прибор,
заведомо не покрывающий нужный класс, и платить за это выбитой рабочей сессией владельца при
каждом замере — не туда. Данные живой работы даёт журнал прогонов тестов, и он копит их сам.

**Что сохранено намеренно.** Отчёты `qa/reports/` — это измерения, а не прибор: на них
держится разбор правил по корзинам, и README с этим файлом ссылаются на их строки. Там же
лежит `qa/reports/baseline-values-file.md` — те самые 56 строк файла ценностей, с которыми
контрольная группа прошла 13 испытаний из 13; это вещественное доказательство к условию в
README, а не фикстура. Содержимое не менялось, только путь.

Возврат к разбору правил по корзинам — по данным журнала, как предписывает `baseline.md:65`.

## Деплой-цикл (незыблемо)

Правки ТОЛЬКО в `runtime/` и `adapters/core-body.md` → `bash tools/build-digests.sh` →
`bash qa/lint.sh` (он же печатает занятость бюджетов) → установщики → проверка живых
копий grep'ом, не верой.

Бюджеты: payload ядра ≤9500 экранированных символов (харнесс молча режет на 10000 —
**замерь ДО правки ядра**), контракт ≤2500, плейбуки ≤6000, probes ≤3600,
дайджесты ≤12000 (Antigravity молча обрезает).

## Чего НЕ делать

- Не добавлять фичи без запроса или урока из памяти: система растёт от настоящих провалов.
- Не возвращать механические замки, которые ничего не добавляют к уже выполняемой работе.
  Маркерный гейт снят дважды — сначала в правилах, теперь физически во всех репозиториях:
  агенты и без него выполняли доказательные прогоны, а замок требовал сверх них отдельный
  файл. Проверка была настоящей, лишним был именно замок.
- Не править сгенерированные дайджесты руками — правится `adapters/core-body.md`.
- Еженедельный самотест — отклонён пользователем дважды. Не предлагать.
- `qa/home-*/.credentials.json` — секреты, не коммитить. Глобальный `CLAUDE.md`
  пользователя не удалять никогда (в нём его `graphify` и `@RTK.md`).
