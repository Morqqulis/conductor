# HANDOFF — состояние проекта Conductor

Обновлено: 2026-07-24. HEAD: `0597e52` (v1.16). Написано для читателя с нулевым контекстом.

## Что это

Conductor — дисциплинарная система для AI-агентов (замена плагина superpowers):
классификация задачи до работы, доказательство до слова «готово» и до коммита,
самообучение через общий журнал уроков. Покрывает **четыре среды**: Claude Code
(ядро + хуки), Cursor, Antigravity, Codex (текстовые дайджесты правил).
Этот репозиторий — источник правды и одновременно дистрибутив.

## Текущее состояние

- Всё v1.16 задеплоено на эту машину и проверено grep'ом живых копий.
- Журнал уроков: `~/.claude/conductor/lessons.md`, ~12 строк (порог переваривания: >20).
- **Не запушено: 7 коммитов** (v1.11–v1.16). Теги стоят до `conductor-v1.10.1`,
  новым версиям теги не ставились.

## Ключевые решения последней волны (v1.11–v1.16)

- **v1.12 — маркерный коммит-гейт УДАЛЁН.** Полевые данные: агенты создавали маркер
  ритуальным `touch` без доказательства — механика сертифицировала ничего. Дисциплина
  теперь текстовая: «коммит — заявление о готовности, свежий прогон до него, строки в
  ответ». Установщики вычищают остатки гейта (hooks.json всех сред, PreToolUse,
  init.templateDir). НЕ восстанавливать механику без новых данных — урок в журнале.
- Скептик-прогон засчитывается как доказательный, если гонял ту же команду и после
  неё не было мутаций (указание пользователя).
- **v1.11/1.11.1 — правило unverified**: фактическое утверждение без доказательства
  из текущей сессии несёт пометку «unverified / from memory» во ВСЕХ ходах; про
  ненаблюдаемые поверхности (кнопки IDE, чужие UI) выдумывать детали запрещено —
  «cannot see that surface» + проверяемая альтернатива.
- **v1.13 — cleanup sweep**: любое удаление/переименование завершено только при
  «поиск старого имени → 0 необъяснённых совпадений» + явная зачистка сирот
  (регистрации, кэши, миграции БД, env, docs).
- **v1.14 — правило rtk** (Rust Token Killer): если `rtk` установлен — чтение/поиск
  через bash (rtk сжимает вывод shell), встроенные инструменты идут мимо него;
  правки файлов — всегда штатными инструментами. Правило спит, пока rtk нет.
- **v1.15 — Codex**: дайджест ставится в `~/.codex/AGENTS.md` (голова цепочки
  инструкций, ~9.5k из 32 КиБ), журнал уроков Codex читает по инструкции (pull).
- **v1.16 — выбор языка** в install-global (меню или `-Language`), подстановка во
  все четыре поверхности; фикс падения на свежей машине (нет `~/.gemini`).

## Незакрытые хвосты (по убыванию важности)

1. **Старые маркерные git-хуки ещё стоят в ~15 рабочих репозиториях** (проверено на
   D:\top\tusi — хук на месте). Пользователю дана одна вставка в PowerShell
   (см. итог сессии v1.12; снимает 4 хука с сентинелем 'conductor gate' по корням
   D:\top, D:\projects, D:\codelabs, Desktop\ika, Desktop\vpn). Пока не выполнена —
   хуки требуют маркер, который больше никто не создаёт: коммиты агентов там будут
   отклоняться. Песочница не пускает агента в D:\ — только руками пользователя.
2. **`git push`** — 7 коммитов локально; теги v1.11+ не созданы (по желанию).
3. **Cursor global rule** — ручной шаг: вставить тело
   `~/.claude/conductor/adapters/cursor/conductor-core.mdc` (готовая копия с
   выбранным языком) в Cursor Settings → Rules. Проектные правила уже стоят.
4. Пользователь планирует **переустановку Windows** и установку **rtk**. Перенос:
   clone → `install.ps1` → `install-global.ps1` (спросит язык) → вручную скопировать
   `~/.claude/conductor/lessons.md` (единственное, что не переезжает с репо).
5. `AGENTS.md` в корне — операционный гид Codex для ЭТОГО репо (пути исправлены в v1.15).

- `qa/home-*/.credentials.json` — секреты, не коммитить. Глобальный CLAUDE.md
  пользователя не удалять никогда.
