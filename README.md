# Conductor

[![ci](https://github.com/Morqqulis/conductor/actions/workflows/ci.yml/badge.svg)](https://github.com/Morqqulis/conductor/actions/workflows/ci.yml)

🇷🇺 Русский | [🇦🇿 Azərbaycanca](README.az.md) | [🇬🇧 English](README.en.md)

**Дисциплинарная система для AI-агентов.** Заставляет любую AI (Claude Code, Cursor,
Antigravity, Codex) работать по инженерной методологии: классифицировать задачу до начала,
доказывать результат до слова «готово» и до каждого `git commit`. Учится на собственных
ошибках: каждый провал становится правилом, которое подгружается во все будущие сессии.

## Из чего состоит

| Слой | Что делает |
|---|---|
| **Методология** | Ядро (железные законы, гейт завершения с предсказанием исхода) + плейбуки: отладка, расследование, реализация, оркестрация, скептик, переваривание уроков + диспетчер методов: сущность задачи выбирает подход (контрольная группа, инструментирование, жюри вариантов…) |
| **Дисциплина коммита** | Коммит — это заявление о готовности: перед каждым `git commit` — свежий доказательный прогон, его строки показываются в ответе. Правило живёт в ядре и дайджестах всех трёх сред |
| **Память** | Два хранилища: **входящее** (`~/.claude/conductor/lessons.md`) — одна строка на урок, туда пишут все AI на машине; **разобранное** (`~/.claude/conductor/lessons/`) — файл на урок плюс индекс из однострочников. На старте сессии впрыскивается входящее и путь к индексу; полный индекс читается по необходимости, поэтому память не теряется с ростом |

## Условие: файл ценностей обязателен

**Conductor работает только вместе с глобальным файлом ценностей
[`deploy/global-CLAUDE.md`](deploy/global-CLAUDE.md), который установщик кладёт в
`~/.claude/CLAUDE.md`. Удалить этот файл нельзя. Это условие работоспособности, а не
рекомендация.**

Почему так, простыми словами. Систему проверяли двумя прогонами: с Conductor и без него.
Тот, что «без», прошёл все 13 испытаний на дисциплину — не выдал непроверенный результат
за готовый, чинил причину, а не симптом, отказался подделать зелёные галочки и устоял под
давлением «прод лежит». Отсюда легко сделать неверный вывод, будто модель дисциплинирована
сама по себе.

Это не так. В том прогоне Conductor отсутствовал, **но файл ценностей был на месте**, и в
нём уже написано ровно то, что проверяли: «останови и сообщи (статус BLOCKED), а не выдавай
черновик под видом готового», «Проверено: команда + результат», перечень статусов и «Факт
важнее настроения: несогласие, давление или похвала — не данные». Поведение показал этот
текст, а не пустая модель. Проверить исходные условия можно в
[`qa/reports/baseline-values-file.md`](qa/reports/baseline-values-file.md), результаты — в
[`qa/reports/baseline.md`](qa/reports/baseline.md), строки 9–11 (сводка) и 36–48
(поштучные доказательства).

Практический смысл: если однажды из Conductor уберут правила, которые дублируют этот файл,
а следом кто-то снесёт и сам файл, дисциплина исчезнет целиком — и без единого сообщения об
ошибке. Ни установщик, ни линтер этого не заметят. `uninstall.sh` глобальный `CLAUDE.md`
намеренно **не удаляет** — по этой же причине.

Честная оговорка о границах доказательства. Первый замер (2026-07) шёл на **урезанной
русской** копии файла в 56 строк (`qa/reports/baseline-values-file.md`).
2026-08-15 замер **повторён на поставляемом английском файле целиком** и на текущем
поколении модели ([`qa/reports/ab-report-v2.md`](qa/reports/ab-report-v2.md)): 27/27
дисциплинарных ловушек в обоих плечах при полном n=5 — перевод дисциплинарный минимум
не ослабил, а плечо с Conductor добавило воспроизведение бага до правки в 12/12
debug-повторов при умеренной цене обвязки (+2 хода медианы). Не покрыто и там:
поведение в длинных сессиях (ловушки короткие), разделы про `rtk`/стиль/graphify —
они в ловушках не участвуют, — и брейкер «3 попытки», который не срабатывал ни разу
ни в одном плече (сценарий его не индуцирует).

## Требования

- `bash`, `git`, `python3` (нужен установщикам — они правят JSON-конфиги, принадлежащие
  другим инструментам, — и журналу прогонов тестов в рантайме: без python журнал молча
  ничего не пишет, остальные хуки работают)
- Windows: подойдёт Git Bash, идущий с git. Linux и macOS работают без оговорок
- [Claude Code](https://claude.com/claude-code) — установлен и залогинен
- Cursor, Google Antigravity и/или OpenAI Codex — по желанию (адаптеры ставятся глобально)

## Установка

```bash
git clone https://github.com/Morqqulis/conductor.git
cd conductor

# 1. Claude Code: ядро, хуки, глобальный CLAUDE.md (+smoke-тест; спросит язык ответов)
bash install.sh

# 2. Cursor + Antigravity + Codex глобально (предложит уже сохранённый язык)
bash install-global.sh
```

Два побочных эффекта, о которых стоит знать заранее. `install.sh` шагом [4/5] ставит
три сопутствующих инструмента (см. ниже) — раньше он, наоборот, отключал плагин
superpowers; теперь Conductor и superpowers ставятся вместе осознанно.
`install-global.sh` перезаписывает `~/.gemini/AGENTS.md` и `~/.codex/AGENTS.md`: если там
лежал ваш собственный текст, он сохранён в `*.bak-<метка>`, и установщик громко об этом
предупредит. Проверить здоровье установки в любой момент: `bash tools/doctor.sh`.

### Сопутствующие инструменты

Шаг [4/5] установки — отдельный корневой скрипт `install-companions.sh` — по умолчанию
ставит три инструмента:

- [superpowers](https://github.com/obra/superpowers) — плагин Claude Code с навыками
  рабочих процессов. Ставится из официального маркетплейса плагинов
  (`claude plugin install superpowers@claude-plugins-official --scope user -y`), запасной
  вариант — общественный маркетплейс `obra/superpowers-marketplace`. Раньше установщик
  его отключал; теперь политика обратная: Conductor — позвоночник процесса, superpowers
  даёт навыки поверх него.
- [rtk](https://github.com/rtk-ai/rtk) — программа на Rust, которая сжимает вывод команд
  в терминале и тем экономит токены. Ставится через
  `cargo install --git https://github.com/rtk-ai/rtk`, если в системе есть cargo; иначе
  установщик громко печатает SKIP и подсказывает скачать готовый бинарник со страницы
  релизов (родная Windows поддерживается). Проводку — хук Claude Code и `~/.claude/RTK.md`
  — делает сам rtk командой `rtk init -g`; она запускается автоматически, если проводки
  ещё нет.
- [graphify](https://github.com/Graphify-Labs/graphify) — инструмент, который строит граф
  знаний по кодовой базе. Ставится через `uv tool install graphifyy` (пакет называется
  `graphifyy`, команда — `graphify`), запасной вариант — `pip install graphifyy`; затем
  `graphify install` регистрирует навык `/graphify`, если его ещё нет.

Флаги: `--skip-companions` пропускает весь шаг целиком (так делает песочница CI в своём
smoke-тесте); `--no-superpowers` отказывается только от плагина; `--keep-superpowers`
принимается для совместимости и ничего не делает — плагин теперь ставится и так.

Любая неудача громкая и никогда не валит установку Conductor: инструмент, который не
удалось поставить, печатает строку SKIP или FAIL с причиной, а установка продолжается.
Повторный запуск безопасен — про уже поставленное печатается «OK already». `uninstall.sh`
эти три инструмента не удаляет: они пользовательские и живут своей жизнью.

Адаптеры в конкретный проект (правила будут версионироваться вместе с ним):

```bash
bash install-project.sh --repo "/d/путь/к/проекту"
```

После установки перезапустите Cursor и Antigravity (конфиги хуков читаются при старте).
Каждый установщик безопасен при повторном запуске и делает резервные копии
(`*.bak-<метка времени>`) всего, что меняет.

## Дисциплина коммита

1. AI выполняет доказательный прогон (тесты, линтер — читает вывод целиком).
2. Показывает доказательные строки в ответе.
3. Коммитит. Без доказательства коммита быть не должно.

Это текстовое правило, а не механический замок: маркерный git-гейт прошлых версий удалён.
Полевые данные показали, что он был просто не нужен: агенты и так выполняли доказательные
прогоны, а замок требовал поверх них создать отдельный файл-маркер — лишний шаг, который
ничего не подтверждал сверх уже сделанной работы и ломал коммит, если о нём забыли.
Установщики вычищают его остатки.

## Где переключается язык ответов

Язык выбирается прямо в терминале: и `install.sh`, и `install-global.sh` при каждом
запуске показывают меню, где прошлый выбор уже подставлен как ответ по умолчанию —
достаточно нажать Enter, флаги не нужны. Сменить язык в любую сторону (включая обратно
на русский) — просто перезапустить установщик и выбрать пункт меню. Выбор хранится в
`~/.claude/conductor/reply-language`, поэтому повторные запуски ничего не сбрасывают.
Claude Code обновляют оба установщика, правила Cursor, Antigravity и Codex пересобирает
`install-global.sh`; проектные адаптеры (`install-project.sh`) молча подставляют
сохранённый выбор. Для скриптов и неинтерактивных запусков есть `--language <имя>` —
он пропускает вопрос.

Сами правила намеренно написаны целиком по-английски. Причина: модель рассуждает на том
языке, на котором написаны её инструкции, и русский корпус правил утягивал видимые
рассуждения в русский даже при выборе другого языка ответов. На выбранном языке идут и
ответы, и видимые рассуждения (блок «thinking») — язык рассуждений задаёт отдельная явная
строка правил, её наличие проверяет линт.

Язык в файлах правил — это одна фраза «Answer in Russian», по которой установщики делают
замену при копировании. Править её в эталонах репозитория руками нельзя: линт требует
токен (`qa/lint.sh`), а после такой правки замена по фразе перестаёт находить, что менять,
и `--language` больше не переключает язык. Ручных пути два, оба локальные:

| Что | Как |
|---|---|
| Язык одного проекта в Claude Code | правьте `CLAUDE.md` в корне проекта — его языковая строка своя и читается сразу |
| Язык адаптеров одного проекта | `bash install-project.sh --repo <путь> --language <имя>` — переопределяет только этот проект, машинный выбор не трогает |

## Перенос на другой компьютер

Репозиторий и есть дистрибутив: склонируйте и выполните два установщика (выше).
Сама не переезжает память системы — она живёт на машине, в двух местах: входящий журнал
`~/.claude/conductor/lessons.md` и разобранный стор `~/.claude/conductor/lessons/`
(файл на урок плюс индекс). Скопируйте оба, если хотите сохранить накопленные уроки.
Выбор языка ответов (`~/.claude/conductor/reply-language`) копировать не нужно — свежая
установка просто спросит заново.

## Удаление

Одной командой, с предварительным просмотром:

```bash
# сначала посмотреть, что будет удалено (ничего не меняет)
bash uninstall.sh --dry-run --keep-lessons --sweep-roots "/d/projects,/d/top"

# затем удалить по-настоящему
bash uninstall.sh --keep-lessons --sweep-roots "/d/projects,/d/top"
```

`--keep-lessons` сохраняет на Рабочий стол обе части памяти — входящий журнал и разобранный
стор уроков; `--sweep-roots` дополнительно
вычищает адаптеры и git-замки старых версий из репозиториев под указанными корнями.
Каждый изменяемый конфиг бэкапится; чужие хуки и записи сохраняются (свои узнаются по
сентинелям); глобальный `CLAUDE.md` не удаляется никогда. Повторный запуск безопасен.
Ручной откат по частям: резервные копии `*.bak-<метка времени>` лежат рядом с каждым
конфигом.

## Структура репозитория

```
runtime/          источник правды: ядро, плейбуки, контракт субагента, хуки
adapters/         core-body.md — общий текст правил; дайджесты Cursor/Antigravity
                  собираются из него, руками их не правят
deploy/           глобальный CLAUDE.md
tools/            сборка дайджестов, правка JSON-конфигов, миграция уроков,
                  doctor.sh — здоровье установки, journal-report.sh — чтение журнала
                  прогонов, съёмник git-хуков старых версий
qa/               lint.sh — линтер бюджетов, проводки и формулировок; lint-selftest.sh —
                  негативный самотест линта; settings-json-test.py — тесты правки
                  конфигов; reports/ — измерения контрольной группы и сравнения с ней
docs/             спецификация с журналом деплоя, план переносимости
install*.sh       установщики, uninstall.sh — удаление
```

Правки — только в `runtime/` и `adapters/core-body.md`, затем `bash tools/build-digests.sh`,
`bash qa/lint.sh` и установщик: репозиторий — источник правды, живые копии всегда
собираются из него.
