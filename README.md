# Conductor

🇷🇺 Русский | [🇦🇿 Azərbaycanca](README.az.md)

**Дисциплинарная система для AI-агентов.** Заставляет любую AI (Claude Code, Cursor,
Antigravity) работать по инженерной методологии: классифицировать задачу до начала,
доказывать результат до слова «готово», и физически не пропускает непроверенный
`git commit`. Учится на собственных ошибках: каждый провал становится правилом,
которое подгружается во все будущие сессии.

## Из чего состоит

| Слой | Что делает |
|---|---|
| **Методология** | Ядро (железные законы, гейт завершения с предсказанием исхода) + плейбуки: отладка, расследование, реализация, оркестрация, скептик, переваривание уроков |
| **Замки** | Трёхслойный коммит-гейт: хук среды (Claude Code / Cursor / Antigravity) + git-хуки в самом репозитории. Коммит проходит только при свежем одноразовом маркере, созданном после доказательного прогона |
| **Обучение** | Журнал уроков (`~/.claude/conductor/lessons.md`): все AI пишут в один файл, свежие уроки впрыскиваются на старте каждой сессии, при переполнении система сама требует переваривания в постоянные правила |

Замки ставятся сами: новые репозитории рождаются с ними (`git init`/`clone`),
существующие защищаются при первом коммите агента.

## Требования

- Windows 10/11, PowerShell (`pwsh` или встроенный), git
- [Claude Code](https://claude.com/claude-code) — установлен и залогинен
- Cursor и/или Google Antigravity — по желанию (адаптеры ставятся глобально)

## Установка

```powershell
git clone https://github.com/Morqqulis/conductor.git
cd conductor

# 1. Claude Code: ядро, хуки, журнал уроков, глобальный CLAUDE.md (+smoke-тест)
pwsh -File install.ps1

# 2. Cursor + Antigravity глобально + git-шаблон для новых репозиториев
pwsh -File install-global.ps1
```

По желанию — замки в уже существующие репозитории (новые получают их автоматически):

```powershell
# один проект
pwsh -File install-git-gate.ps1 -Repo "D:\путь\к\проекту"

# все проекты под корнем сразу
pwsh -File install-git-gate.ps1 -Sweep "D:\projects"
```

Адаптеры в конкретный проект (правила будут версионироваться вместе с ним):

```powershell
pwsh -File install-cursor.ps1      -Repo "D:\путь\к\проекту"
pwsh -File install-antigravity.ps1 -Repo "D:\путь\к\проекту"
```

После установки перезапустите Cursor и Antigravity (конфиги хуков читаются при старте).
Каждый установщик безопасен при повторном запуске и делает резервные копии
(`*.bak-<метка времени>`) всего, что меняет.

## Как работает коммит-гейт

1. AI выполняет доказательный прогон (тесты, линтер — читает вывод целиком).
2. **Отдельной командой** создаёт одноразовый маркер:
   `touch "$(git rev-parse --git-path conductor-verified)"`
3. Коммитит. Хук `post-commit` съедает маркер — следующему коммиту нужно своё
   доказательство. Без маркера коммит отклоняется с инструкцией; `--no-verify`
   и подмена `core.hooksPath` запрещены на уровне хуков среды.

## Где переключается язык ответов

Правило «отвечай по-русски, простым языком» лежит в трёх местах — правьте нужное
и перезапустите соответствующий установщик:

| Среда | Файл и раздел | После правки |
|---|---|---|
| Claude Code, все проекты | [`deploy/global-CLAUDE.md`](deploy/global-CLAUDE.md) → раздел **«5. Язык и стиль ответа»** | `pwsh -File install.ps1` |
| Claude Code, один проект | `CLAUDE.md` в корне проекта → раздел **«5. Язык и отчёт»** | ничего — читается сразу |
| Cursor и Antigravity | [`adapters/cursor/conductor-core.mdc`](adapters/cursor/conductor-core.mdc) и [`adapters/antigravity/conductor-core.md`](adapters/antigravity/conductor-core.md) → раздел **«Language and reporting»** | `pwsh -File install-global.ps1` |

Например, для азербайджанского замените в этих разделах «Answer in Russian» на
«Answer in Azerbaijani» (и «на русском» → «на азербайджанском» в CLAUDE.md).

## Перенос на другой компьютер

Репозиторий и есть дистрибутив: склонируйте и выполните два установщика (выше).
Единственное, что не переезжает само, — журнал накопленных уроков
`~/.claude/conductor/lessons.md`: скопируйте этот файл вручную, если хотите
сохранить память системы. Переваренные уроки уже живут в плейбуках и переедут
с репозиторием.

## Удаление

Одной командой, с предварительным просмотром:

```powershell
# сначала посмотреть, что будет удалено (ничего не меняет)
pwsh -File uninstall.ps1 -WhatIf -KeepLessons -SweepRoots "D:\projects,D:\top"

# затем удалить по-настоящему
pwsh -File uninstall.ps1 -KeepLessons -SweepRoots "D:\projects,D:\top"
```

`-KeepLessons` сохраняет журнал уроков на Рабочий стол; `-SweepRoots` дополнительно
вычищает git-замки и адаптеры из репозиториев под указанными корнями. Каждый
изменяемый конфиг бэкапится; чужие хуки и записи сохраняются (свои узнаются по
сентинелям); ваши старые хуки `*.pre-conductor` возвращаются на место; глобальный
`CLAUDE.md` не удаляется никогда. Повторный запуск безопасен.

Ручной откат по частям: резервные копии `*.bak-<метка времени>` лежат рядом с каждым
конфигом; замок из одного репозитория — четыре файла в `.git/hooks/`; шаблон новых
репозиториев — `git config --global --unset init.templateDir`.

## Структура репозитория

```
runtime/          источник правды: ядро, плейбуки, хуки сред, git-хуки
adapters/         дайджесты и гейты для Cursor и Antigravity
deploy/           глобальный CLAUDE.md
qa/               линтер бюджетов и проводки, бенчмарк-сценарии
docs/             спецификация с журналом деплоя, план переносимости
install*.ps1      установщики (см. выше)
```

Правки — только в `runtime/` и `adapters/`, затем `qa\lint.ps1` и установщик:
репозиторий — источник правды, живые копии всегда собираются из него.
