# Conductor

🇷🇺 Русский | [🇦🇿 Azərbaycanca](README.az.md)

**Дисциплинарная система для AI-агентов.** Заставляет любую AI (Claude Code, Cursor,
Antigravity, Codex) работать по инженерной методологии: классифицировать задачу до начала,
доказывать результат до слова «готово» и до каждого `git commit`. Учится на собственных
ошибках: каждый провал становится правилом, которое подгружается во все будущие сессии.

## Из чего состоит

| Слой | Что делает |
|---|---|
| **Методология** | Ядро (железные законы, гейт завершения с предсказанием исхода) + плейбуки: отладка, расследование, реализация, оркестрация, скептик, переваривание уроков + диспетчер методов: сущность задачи выбирает подход (контрольная группа, инструментирование, жюри вариантов…) |
| **Дисциплина коммита** | Коммит — это заявление о готовности: перед каждым `git commit` — свежий доказательный прогон, его строки показываются в ответе. Правило живёт в ядре и дайджестах всех трёх сред |
| **Память** | Два хранилища: **входящее** (`~/.claude/conductor/lessons.md`) — одна строка на урок, туда пишут все AI на машине; **разобранное** (`~/.claude/conductor/lessons/`) — файл на урок плюс индекс из однострочников. На старте сессии впрыскивается входящее и путь к индексу; полный индекс читается по необходимости, поэтому память не теряется с ростом |

## Условие: файл ценностей обязателен

**Conductor работает только вместе с глобальным файлом ценностей
[`deploy/global-CLAUDE.md`](deploy/global-CLAUDE.md), который установщик кладёт в
`~/.claude/CLAUDE.md`. Удалить этот файл нельзя. Это условие работоспособности, а не
рекомендация.**

Почему так, простыми словами. Систему проверяли двумя прогонами: с Conductor и без него.
Тот, что «без», прошёл все 13 испытаний на дисциплину — не выдал непроверенный результат
за готовый, чинил причину, а не симптом, отказался подделать зелёные галочки и устоял под
давлением «прод лежит». Отсюда легко сделать неверный вывод, будто модель дисциплинирована
сама по себе.

Это не так. В том прогоне Conductor отсутствовал, **но файл ценностей был на месте**, и в
нём уже написано ровно то, что проверяли: «останови и сообщи (статус BLOCKED), а не выдавай
черновик под видом готового», «Проверено: команда + результат», перечень статусов и «Факт
важнее настроения: несогласие, давление или похвала — не данные». Поведение показал этот
текст, а не пустая модель. Проверить исходные условия можно в
[`qa/reports/baseline-values-file.md`](qa/reports/baseline-values-file.md), результаты — в
[`qa/reports/baseline.md`](qa/reports/baseline.md), строки 9–11 (сводка) и 36–48
(поштучные доказательства).

Практический смысл: если однажды из Conductor уберут правила, которые дублируют этот файл,
а следом кто-то снесёт и сам файл, дисциплина исчезнет целиком — и без единого сообщения об
ошибке. Ни установщик, ни линтер этого не заметят. `uninstall.sh` глобальный `CLAUDE.md`
намеренно **не удаляет** — по этой же причине.

Честная оговорка о границах доказательства. Замер проводился на **урезанной** копии файла в
56 строк, а установщик кладёт полную версию в 133 строки. Совпадают в них именно
дисциплинарные разделы — те, что процитированы выше; остальные 77 строк (правило про `rtk`,
разделы 5.1–5.4 про стиль ответа, расширенные требования к тестам безопасности, хвост про
graphify) в замерах не участвовали никогда. Поэтому доказано следующее: **дисциплину держит
процитированный минимум внутри файла ценностей.** Про остальную его часть данных нет — ни
за, ни против.

## Требования

- `bash`, `git`, `python3` (последний нужен только установщикам — они правят JSON-конфиги,
  принадлежащие другим инструментам, и делать это текстом нельзя)
- Windows: подойдёт Git Bash, идущий с git. Linux и macOS работают без оговорок
- [Claude Code](https://claude.com/claude-code) — установлен и залогинен
- Cursor, Google Antigravity и/или OpenAI Codex — по желанию (адаптеры ставятся глобально)

## Установка

```bash
git clone https://github.com/Morqqulis/conductor.git
cd conductor

# 1. Claude Code: ядро, хуки, глобальный CLAUDE.md (+smoke-тест)
bash install.sh

# 2. Cursor + Antigravity + Codex глобально (спросит язык ответов)
bash install-global.sh
```

Адаптеры в конкретный проект (правила будут версионироваться вместе с ним):

```bash
bash install-project.sh --repo "/d/путь/к/проекту"
```

После установки перезапустите Cursor и Antigravity (конфиги хуков читаются при старте).
Каждый установщик безопасен при повторном запуске и делает резервные копии
(`*.bak-<метка времени>`) всего, что меняет.

## Дисциплина коммита

1. AI выполняет доказательный прогон (тесты, линтер — читает вывод целиком).
2. Показывает доказательные строки в ответе.
3. Коммитит. Без доказательства коммита быть не должно; упавший хук — сигнал чинить,
   а не обходить (`--no-verify` — нарушение).

Это текстовое правило, а не механический замок: маркерный git-гейт прошлых версий удалён.
Полевые данные показали, что он был просто не нужен: агенты и так выполняли доказательные
прогоны, а замок требовал поверх них создать отдельный файл-маркер — лишний шаг, который
ничего не подтверждал сверх уже сделанной работы и ломал коммит, если о нём забыли.
Установщики вычищают его остатки.

## Где переключается язык ответов

Простой путь: перезапустите `install-global.sh` — он спросит язык (или задайте сразу:
`bash install-global.sh --language Azerbaijani`) и подставит его в глобальные правила всех
сред, включая готовый для вставки файл правила Cursor. Для смены обратно на русский
сначала выполните `install.sh` (восстановит эталон), затем `install-global.sh`.

Ручной путь — правило лежит в трёх местах, правьте нужное и перезапустите
соответствующий установщик:

| Среда | Файл и раздел | После правки |
|---|---|---|
| Claude Code, все проекты | [`deploy/global-CLAUDE.md`](deploy/global-CLAUDE.md) → раздел **«5. Язык и стиль ответа»** | `bash install.sh` |
| Claude Code, один проект | `CLAUDE.md` в корне проекта → раздел **«5. Язык и отчёт»** | ничего — читается сразу |
| Cursor, Antigravity и Codex | [`adapters/core-body.md`](adapters/core-body.md) → раздел **«Language and reporting»**, затем `bash tools/build-digests.sh` | `bash install-global.sh` |

Например, для азербайджанского замените в этих разделах «Answer in Russian» на
«Answer in Azerbaijani» (и «на русском» → «на азербайджанском» в CLAUDE.md).

## Перенос на другой компьютер

Репозиторий и есть дистрибутив: склонируйте и выполните два установщика (выше).
Единственное, что не переезжает само, — журнал накопленных уроков
`~/.claude/conductor/lessons.md`: скопируйте этот файл вручную, если хотите
сохранить память системы. Переваренные уроки уже живут в плейбуках и переедут
с репозиторием.

## Удаление

Одной командой, с предварительным просмотром:

```bash
# сначала посмотреть, что будет удалено (ничего не меняет)
bash uninstall.sh --dry-run --keep-lessons --sweep-roots "/d/projects,/d/top"

# затем удалить по-настоящему
bash uninstall.sh --keep-lessons --sweep-roots "/d/projects,/d/top"
```

`--keep-lessons` сохраняет журнал уроков на Рабочий стол; `--sweep-roots` дополнительно
вычищает адаптеры и git-замки старых версий из репозиториев под указанными корнями.
Каждый изменяемый конфиг бэкапится; чужие хуки и записи сохраняются (свои узнаются по
сентинелям); глобальный `CLAUDE.md` не удаляется никогда. Повторный запуск безопасен.
Ручной откат по частям: резервные копии `*.bak-<метка времени>` лежат рядом с каждым
конфигом.

## Структура репозитория

```
runtime/          источник правды: ядро, плейбуки, контракт субагента, хуки
adapters/         core-body.md — общий текст правил; дайджесты Cursor/Antigravity
                  собираются из него, руками их не правят
deploy/           глобальный CLAUDE.md
tools/            сборка дайджестов, правка JSON-конфигов, миграция уроков,
                  съёмник git-хуков старых версий
qa/               lint.sh — линтер бюджетов, проводки и формулировок;
                  reports/ — измерения контрольной группы и сравнения с ней
docs/             спецификация с журналом деплоя, план переносимости
install*.sh       установщики, uninstall.sh — удаление
```

Правки — только в `runtime/` и `adapters/core-body.md`, затем `bash tools/build-digests.sh`,
`bash qa/lint.sh` и установщик: репозиторий — источник правды, живые копии всегда
собираются из него.
