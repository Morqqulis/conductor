# Глобальный CLI Conductor: установка, обновление и удаление

Статус: границы и подход подтверждены пользователем; ход реализации и доказательства
зафиксированы в планах ниже. Это контракт, не отчёт о завершении.
Планы для проверки перед исполнением:
[глобальный CLI](../plans/2026-09-27-global-cli-lifecycle.md) и
[RTK/Graphify](../plans/2026-09-27-companion-updates.md).
Уточнение пользователя: глобальный CLI для установки, обновления и удаления, без GUI;
RTK/Graphify обновляются при установке и обновлении Conductor, а не отдельной задачей пользователя.
Дата: 2026-09-27. Основание: запрос закрыть оставшиеся пункты, кроме падения Python.

## Цель и границы

Одна глобальная установка в профиль пользователя обслуживает все его проекты; установка
в каждый репозиторий не требуется. Установка, повторная установка и CLI-обновление должны
сохранять личные правила, память и выбранный язык; после сбоя должна существовать
проверяемая возможность восстановления. Конфигурация отдельных проектов остаётся
отдельной от глобальных правил. Поддерживаются Windows/Git Bash и Linux, а документация
остаётся на русском, английском и азербайджанском.

Пользовательский интерфейс ограничен установкой, обновлением и удалением Conductor.
Безопасность этих операций исправляется на существующей основе. Установка Superpowers
сохраняется; RTK и Graphify получают последние стабильные версии при установке и обновлении.
Внутреннее разделение реализации на части не добавляет пользователю ручных шагов.
Настольное приложение и расследование падения Python исключены пользователем.
Новая база данных, сервер, учётная запись, переписывание всего на Rust и автоматическое
расширение правил не требуются. Решение не должно создавать задел ради будущего GUI.

## Наблюдаемое исходное состояние

- `install.sh` вызывает `tools/install-preflight.py`, затем меняет файлы копированием
  и вызывает регистрацию CLI. Снимки первоначальной установки требуют ручного восстановления.
- `runtime/updater/transaction.py` уже сохраняет байты/права, сравнивает исходное состояние
  и откатывает контролируемую ошибку. `lock.py` используется CLI update/rollback.
- `install-global.sh` делает дополнительные изменения настроек и удаляет старый шаблон Git.
  Они не входят в одну общую транзакцию с основной установкой.
- Данные уроков, журналов и результатов проверок не являются установочным содержимым.
- Дополнительные инструменты хранятся отдельно от удаляемого runtime Conductor.

## Критерии выбора

1. Никакого необъяснённого перезаписывания личных или изменившихся файлов.
2. Отказ резервирования происходит до первого изменения установленного содержимого.
3. Один общий замок установки, обновления и восстановления.
4. Восстановление после обычной ошибки и после аварийного завершения процесса.
5. Согласованное поведение существующих CLI-команд и установочных скриптов.
6. Совместимость команд, языков и существующего формата памяти.

## Два варианта

**Обёртка вокруг нынешних скриптов.** Минимально меняет команды, но должна угадывать все
их побочные действия. Невозможно безопасно отличить позднюю личную правку от частично
выполненного скрипта, если заранее не известно ожидаемое содержимое каждого файла.

**Единая подготовка изменений и транзакция.** Сначала вычисляет конкретные новые файлы
и разрешённые изменения настроек, затем сохраняет снимок и применяет изменения с проверкой.
Требует переноса существующих операций, зато даёт общие правила владения и восстановления.

Рекомендация: второй вариант. Это расширение существующего Python-механизма, не новый
параллельный установщик. Shell-скрипты остаются совместимыми точками входа.

## Поведение

### Три основных действия

- Установка: прежний запуск из терминала без clone сохраняется; `conductor install`
  использует тот же глобальный механизм после появления CLI. Отсутствующие RTK/Graphify
  устанавливаются, существующие обновляются; явный отказ от companions сохраняется.
- `conductor update`: обновляет глобальный Conductor и установленные RTK/Graphify.
  Отсутствующие инструменты отмечаются как отсутствующие, не добавляются неожиданно.
  Актуальная версия Conductor не пропускает проверку версий этих инструментов.
  `update --check` остаётся проверкой без установки и других изменений.
- `conductor uninstall`: удаляет глобальную установку Conductor. Самостоятельный
  `uninstall.sh` остаётся и использует тот же механизм, чтобы поведение не расходилось.
  RTK, Graphify, Superpowers и личные правила проектов не удаляются. Сохранение уроков
  и возможность явного удаления без сохранения остаются отдельным выбором пользователя.

Существующие диагностические `status` и `rollback` не удаляются ради сокращения списка
команд. Новых фоновых служб, GUI и установки в каждый проект не добавляется.

### Подготовка

Установщик проверяет аргументы, зависимости, пути без ссылок и читаемость исходников,
затем получает общий замок. Язык выбирается один раз: явный параметр, диалог с сохранённым
значением, сохранённое значение для неинтерактивного запуска, русский по умолчанию.
Неправильный параметр не меняет установленные файлы.

Подготовка даёт перечень файлов с прежними и ожидаемыми байтами/правами, компонентами,
происхождением и проверками. `payload.py` остаётся общим источником рендеринга путей,
языка и программных файлов. Содержимое source checkout не является личной памятью.

При повторной установке изменённый управляемый файл сохраняется и вызывает отказ,
как уже делает CLI update. При первой явной установке замена существующего файла правил
допустима только с заметным предупреждением и проверенным восстанавливаемым снимком,
сохраняя нынешний контракт установки. `--skip-global-md` оставляет личный CLAUDE.md нетронутым.
Чужой CLI с именем `conductor` никогда не перезаписывается.

### Применение и восстановление

Перед первой записью сохраняются снимок и журнал незавершённой операции в приватном
каталоге состояния, не внутри runtime. Замок удерживается до проверки и закрытия журнала.
Каждый файл заменяется отдельно атомарно; целиком набор файлов атомарным не объявляется.

Перед каждой записью сравнивается ранее наблюдённое состояние. После записи проверяются
байты и, где применимо, права. Ошибка запускает восстановление только собственных изменений.
Если файл изменился посторонним процессом, обе доступные версии сохраняются, операция
завершается ошибкой с путём резервной копии; чужие изменения не стираются.

Маркер версии записывается последним, после проверки новых исполняемых точек входа и
точно зарегистрированных hooks. Проверка не должна зависеть от старого маркера версии.
Неудачная проверка не оставляет новую версию помеченной установленной.

Следующая изменяющая команда под тем же замком сначала обнаруживает незавершённую
операцию. Она безопасно восстанавливает снимок либо сообщает конфликт и отказывается
продолжать. CLI rollback принимает как снимки обновления, так и новой установки.
Status показывает незавершённость, не выдавая частичную установку за исправную.

### Настройки и прежние механизмы

Редактирование JSON использует имеющийся парсер принадлежности hooks; чужие ключи и
команды сохраняются. Удаление прежних файлов допустимо лишь при доказанной принадлежности,
в границах управляемых корней и после резервирования. Изменения настроек Cursor,
Antigravity и Git учитываются в плане явно, а не запускаются вне контроля транзакции.
Смешанные или неизвестные каталоги не удаляются целиком.

Уроки, результаты проверок, пользовательские настройки моделей, ключи и файлы вне
разрешённых целей не участвуют в замене. Зарегистрированные компоненты сохраняются;
выбор scope не является неявным удалением остальных компонентов.

### Дополнительные инструменты

Установка дополнительных инструментов запускается после успешной транзакции Conductor.
Её результаты сообщаются отдельно: сбой Graphify/RTK/Superpowers не отменяет успешно
установленный Conductor и не превращается в зелёное подтверждение готовности инструмента.
При каждой обычной установке, повторной установке и `conductor update` автоматически
проверяются последние стабильные выпуски RTK/Graphify и обновляются имеющиеся копии.
Отсутствующие инструменты устанавливаются при установке Conductor, но не добавляются
одним обновлением, если их у пользователя нет. Наличие рабочего бинарника не означает,
что его версия актуальна. Уже актуальный Conductor не блокирует обновление этих инструментов.
Отдельного фонового процесса нет; предварительные сборки не выбираются автоматически.
Явный пропуск companions и режим проверки без записи сохраняются как осознанные исключения.
Автообновление Superpowers не запрошено. Обновление Graphify как инструмента не запускает
пересборку карт пользовательских проектов.
Уточнение, согласованное 2026-09-27: распознанные uv/Cargo-установки не обновляются
в хранилище менеджера. Создаётся отдельная управляемая копия с проверенным приоритетом
PATH; оригинальные программы и данные менеджера сохраняются. Прежние инструкции
обновляются только при совпадении с оригинальным пакетом или зарегистрированной копией.
Неизвестные программы и личные изменения не присваиваются Conductor.
Сбой одного инструмента должен сообщаться отдельно и не называться успехом.

## Проверяемая приёмка

- Новая и повторная установка для all/claude/global, три языка, пропуск CLAUDE.md.
- Глобальная установка без clone и повтор через CLI используют один механизм;
  текущая директория проекта не становится целью установки.
- Удаление через CLI и отдельный скрипт эквивалентно, не требует исходного checkout,
  сохраняет независимые инструменты и личные правила; проверены режимы сохранения уроков.
- При установке отсутствующий инструмент появляется в актуальной версии, старый обновляется;
  при update обновляются имеющиеся инструменты, в том числе при актуальном Conductor.
- Недоступный сервер версий или неудачное обновление не дают ложного сообщения об успехе;
  прежняя рабочая копия инструмента и настройки сохраняются, результат указан по каждому.
- Пути с пробелами, кириллицей и `&`; данные пути не интерпретируются как шаблон или команда.
- Прежние личные правила восстановимы; память и посторонние JSON-настройки неизменны.
- Ошибка резервирования, середины записи и итоговой проверки: ненулевой выход,
  прежнее содержимое восстановлено, новая версия не записана.
- Принудительное завершение процесса во время записи: следующая команда обнаруживает
  незавершённую операцию и восстанавливает её без перезаписи поздних чужих правок.
- Параллельные install/update/rollback не меняют файлы одновременно.
- Откат новой установки и обновления; конфликт после личной правки; права POSIX.
- Запуск без checkout через существующий bootstrap; проверка установленных команд.
- Подмена ссылки, выход за корень, неизвестный CLI и недостоверный state отклоняются.
- Проверки работают на Windows и Linux; отключение каждой новой защиты действительно
  вызывает провал соответствующего отрицательного теста.

## Граница завершения

Запрос закрывается исправлением рисков существующего CLI, проверкой установки/обновления/
удаления и автоматического обновления RTK/Graphify в этих потоках. GUI и новые обязательные
правила для агентов не являются критериями завершения. Другие функции не добавляются
под видом исправлений.

Обновление карты Graphify выполняется после связного пакета изменений. Пока пакет меняется,
источником истины остаются файлы, а не ранее собранная карта.
