# Простой язык в ответах: замер 2026-11-04

## Итог

Новое правило о простом языке почти вчетверо уменьшило число терминов, которые остаются
в ответе без объяснения: в среднем 13,3 → 3,7 на ответ. Это одна задача и по три ответа
на вариант правил, поэтому результат — заметный сдвиг, а не окончательное доказательство.

| Вариант правил | Необъяснённых терминов, в среднем | Объяснено терминов | Статус с пояснением | Ответ на русском |
|---|---|---|---|---|
| Старые (`main` на `7413df6`) | 13,3 | 24% | 0 из 3 | 3 из 3 |
| Новые, первая редакция | 7,7 | 65% | 3 из 3 | 3 из 3 |
| Новые + слова программистов | 5,7 | 64% | 3 из 3 | **2 из 3** |
| Новые + исправленный запасной язык | **3,7** | 69% | 3 из 3 | 3 из 3 |

Стоимость всего замера — около 4,4 доллара (12 ответов и 12 оценок).

## Как мерили

- Задача стенда `rootcause` («тесты падают с ошибкой `toFixed is not a function`, почини»),
  ветка стенда с Conductor (`qa/bench/run.sh --arm conductor`). Старые правила запускались
  из отдельной копии проекта на коммите `7413df6`, новые — из рабочей копии.
- Оценщик — отдельный запуск Claude с неизменной инструкцией
  (`qa/bench/judge-plain-language.py`): выписать каждое слово, незнакомое человеку без
  технической подготовки, и отметить, объяснено ли оно там, где появилось. Ответы
  перемешаны под номерами, оценщик не знает, какие правила их породили.
- Механическая мера в том же скрипте: латинские слова вне кода и пояснение метки статуса.
- Сырые оценки по каждому ответу: `plain-language-2026-11-04.samples.json`.

## Что нашёл замер по ходу

1. После первой редакции чаще всего без объяснения оставались слова программистов:
   «функция», «метод», «тест», «пустая строка», `null`, а также пути к файлам. Их добавили
   в список видов терминов и в правило «скажи, для чего файл».
2. Во втором раунде один ответ из трёх пришёл целиком по-английски. Причина — новое
   напоминание: без файла сохранённого языка оно говорило «отвечай на языке
   пользователя», а задача стенда написана по-английски. Исправленная формулировка
   отсылает к языку, заданному правилами; в третьем раунде все ответы на русском.

## Чего замер не показывает

- Одна короткая задача; длинные сессии, вопросы без кода и другие языки не проверялись.
- Один оценщик той же модели; его решения о том, «объяснено ли», могут расходиться
  с мнением живого читателя.
- Изменение правила за пределами Claude Code (Cursor, Antigravity, Codex) не измерялось.
