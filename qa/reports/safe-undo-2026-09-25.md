# Безопасная отмена — 2026-09-25

Исправлены debugging/implementing, dirty-tree probe и общий источник дайджестов.
Контрольная отмена теперь выполняется в отдельной копии текущего состояния: снимаются
только собственные фрагменты исправления, текущий тест сохраняется даже в том же файле.
До задачи сохраняются точные байты и существование файлов, включая dirty/untracked.
Перед отменой проверяется ожидаемое состояние; поздние изменения не перезаписываются.
Для удаления нового файла нужны доказанные исходное отсутствие и собственное владение.
Обычная текстовая правка T1 по-прежнему не требует теста, сборки или ритуала.

## Исполняемое доказательство

`qa/safe-undo-test.py` выполняет Bash-пример, извлечённый прямо из debugging.md,
на трёх одноразовых репозиториях. Это не самостоятельная копия алгоритма защиты.

| Сценарий | Старый документированный HEAD-fallback | Новый пример |
|---|---|---|
| Уже изменённый пользователем tracked-файл | Данные и текущий тест потеряны, хотя Git exit 0 | Данные и тест сохранены, результат 0/1/0 |
| Существовавший untracked-файл с CRLF | Перенаправление обнулило файл до Git exit 128 | Байты и CRLF сохранены, результат 0/1/0 |
| Исправление и тест вместе; позже добавлена чужая строка | Потеря данных и теста | Отказ без изменения оригинала; продолжение в отдельной копии, результат 0/1/0 |

Дополнительно проверены собственный новый файл, восстановление собственного удаления
из снимка и отказ при появлении чужого файла на его месте.

- Baseline: `python qa/safe-undo-test.py --baseline` — 3 сценария, 3 нарушения, exit 1.
- Новый пример: `python qa/safe-undo-test.py` — 3 сценария, 0 нарушений, exit 0.
- Удалён только expected-state guard из отдельной копии инструкции: 4 нарушения,
  включая изменение файла при несовпадении ожидаемых байтов, exit 1.
- Возврат guard: те же сценарии, 0 нарушений, exit 0. Main повторил положительный
  прогон после интеграции. Временные репозитории процедуры удалены.

Пример использует командный `core.autocrlf=false`: первая проверка обнаружила, что
системная настройка Git преобразовывала LF в CRLF. Глобальная настройка не менялась.
Архив исходников и полные журналы сохранены в рабочем временном каталоге задачи,
в `safe-undo-evidence/`; отмена интеграции — из `integration-before/` после проверки
текущего состояния. Полный stash/reset/clean над рабочим деревом не выполнялся.

## Короткая независимая проба решений

Навык writing-skills потребовал отдельную проверку решений, не только алгоритма.
Двум свежим исполнителям дали одинаковые три ситуации и границу T1: первому — старые
playbooks, второму — новые. Записи ответов и общий запрос без правок сохранены в
`safe-undo-2026-09-25.samples.json`. Реальные файлы в этой пробе не изменялись.

Baseline уже отказался от подмены HEAD и сохранил текущий тест в своих решениях:
нельзя приписывать это улучшение новому тексту. Однако он не назвал изолированную
копию в первых двух случаях и в третьем требовал согласования только при пересечении
правок. Новый ответ явно требует текущую изолированную копию, проверку ожидаемых
байтов и остановку с сохранением обеих версий при несовпадении; не выдумывает наличие
снимков. Оба ответа допускают только просмотр простой надписи.

Это маленькая проверка выбора действий, не статистика, не исполнение действий моделью
и не гарантия поведения всех агентов. Дефект старой процедуры независимо подтверждён
реальным исполнением выше. Эквивалентность сокращений остального текста оценена чтением
diff, а не отдельным испытанием каждого правила.

Интеграционный lint поймал удалённый при сокращении языковой токен. Восстановлены
`Answer in Russian`, явная строка языка рассуждений и `Explain the result clearly.`.
После пересборки дайджестов lint проходит; лимит 12000 байт не повышен.
